# Кандидатогенерация услуг Авито

**Recall@50 на скрытом тесте: 0.895370.** 
Решение находит до 50 объявлений
для каждого поискового запроса. Весь код, обучение и анализ находятся в
[`solution.ipynb`](solution.ipynb).

## Подход

Из корпуса собирается общий пул кандидатов. CatBoost оценивает их и оставляет 50.

| Компонент | Что он учитывает |
|---|---|
| BM25 и символьный TF-IDF | Совпадения в заголовке, описании и параметрах, словоформы и опечатки |
| EmbeddingGemma 300M | Близость смысла запроса и объявления, в том числе с фильтрами поиска |
| История взаимодействий | Выбор объявлений по похожим запросам, популярность и подкатегории |
| География | Город, расстояние, выезд и удалённый формат услуги |
| CatBoost PairLogit | Совместный отбор по поисковым оценкам, фильтрам, географии, цене, рейтингу и отзывам |

Multilingual E5 использован как базовый семантический поиск. Дополнительно проверены
EmbeddingGemma, их объединение и короткое дообучение E5. Лучший результат на dev
получила **Gemma с калибровкой географических и исторических сигналов**.
Она дала +0.8 п.п. к базовому решению и использует один энкодер в финальном поиске.
Gemma не дообучалась. На данных задания обучается CatBoost, который выбирает
сложные негативы вторым проходом только по обучающей части.

## Качество

Метрика считается как среднее Recall@50 по запросам. Все варианты ниже проверены
на одних и тех же данных. Основной критерий выбора: dev с новыми текстами запросов.

| Вариант | Dev, 1 500 запросов | Warm dev, 500 запросов |
|---|---:|---:|
| E5, базовый вариант | 0.932444 | 0.938333 |
| E5 + обработка текста | 0.927778 | 0.942333 |
| E5 + обработка текста и география | 0.928778 | 0.938333 |
| E5 + дополнительные контексты | 0.932778 | 0.946333 |
| E5 + сложные негативы | 0.928778 | 0.938333 |
| Gemma без калибровки | 0.934111 | 0.948333 |
| **Gemma с калибровкой** | **0.940444** | **0.944333** |
| E5 + Gemma с калибровкой | 0.940111 | 0.946333 |
| Дообученный E5 | 0.931444 | 0.948333 |

| Итоговая проверка | Запросов | Recall@50 |
|---|---:|---:|
| Отложенная локальная выборка, после выбора конфигурации | 1 500 | 0.935389 |
| Скрытый тест платформы | 2 452 | **0.895370** |

Полнота общего пула выбранного решения на dev составляет **0.976333**.
В среднем из 690 кандидатов отбираются 50. Таблицы извлечены из сохранённого
вывода ноутбука и доступны в [`reports/final_run/`](reports/final_run/).
Скрытый тест оценён платформой после ручной отправки файла.

## Валидация и анализ

Тексты запросов fit, dev и test разделены без пересечений после нормализации.
Их взаимодействия исключены из истории, по которой строятся признаки.
Fit содержит 11 723 контекста для 6 000 текстов. В warm dev текст известен истории,
но все взаимодействия выбранного сочетания города, фильтров, категории и доставки отложены.
Локальный корпус содержит 203 683 объявления и одинаков для всех экспериментов.
После оценки test финальный CatBoost обучается на объединённых размеченных частях.
История пересчитывается по полному train, финальный поиск идёт только по benchmark-корпусу.

Анализ учитывает, потерялось ли объявление при поиске или при отборе 50 кандидатов.
Для услуг с общим заголовком добавлен поиск по описанию. Смешанные русские и латинские
буквы нормализуются общим правилом. География учитывает выезд и удалённые услуги
без жёсткого ограничения городом. Отчёт содержит ошибки, срезы, важности признаков
и парный bootstrap сравнения с базовым решением.

## Данные и окружение

Скачайте [архив](https://disk.yandex.ru/d/sNhfo0YOjGtufg) и распакуйте три файла:

| Файл | Строк | Назначение |
|---|---:|---|
| `train.parquet` | 497 673 | Положительные взаимодействия для обучения и локальной проверки |
| `benchmark_queries.parquet` | 2 452 | Запросы для итогового ответа |
| `benchmark_items.parquet` | 189 212 | Корпус объявлений для итогового ответа |

Полный прогон выполнен в **Kaggle, Python 3.12.13, две Tesla T4 по 15 GiB,
30 GiB RAM**. Версии основных зависимостей закреплены в
[`requirements.txt`](requirements.txt): Transformers 4.57.6,
Sentence Transformers 5.1.1, CatBoost 1.2.8, NumPy 2.2.6, pandas 2.2.3.
PyTorch устанавливается отдельно под оборудование. Notebook сохраняет фактические
версии пакетов, CUDA и список GPU в `iteration_summary.json`.

Для полного локального обучения рекомендуется NVIDIA GPU с 16 GB VRAM,
32 GB RAM и 25 GB свободного диска. Доступные CUDA-устройства определяются автоматически.
На CPU также предусмотрен запуск, но полный эксперимент рассчитан на GPU.
Gemma использует все доступные GPU, E5 дообучается на одной, CatBoost работает на CPU.

## Локальный запуск

1. Откройте терминал в корне скачанного репозитория. Подготовьте Python 3.12:

   ```bash
   python3.12 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   ```

   В Windows используйте `py -3.12` вместо `python3.12`,
   команда активации: `.venv\Scripts\activate`.

2. Установите PyTorch. Для Linux с NVIDIA и драйвером, поддерживающим CUDA 12.8:

   ```bash
   python -m pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cu128
   ```

   Для CPU на Linux/Windows замените `cu128` на `cpu`. На macOS используйте
   `python -m pip install torch==2.10.0`. Другие варианты приведены в
   [официальных инструкциях PyTorch](https://pytorch.org/get-started/previous-versions/#v2100).

3. Установите зависимости и Jupyter:

   ```bash
   python -m pip install -r requirements.txt jupyterlab ipykernel
   python -m ipykernel install --user --name avito-services --display-name "Python (avito-services)"
   ```

4. Примите условия на странице [EmbeddingGemma](https://huggingface.co/google/embeddinggemma-300m)
   и выполните `hf auth login` в терминале. Авторизация нужна для первого скачивания весов.
   Сохранённые локально модели загружаются без сети.

5. Разместите файлы и откройте ноутбук:

   ```text
   avito-services-candidate-generation/
   ├── solution.ipynb
   ├── requirements.txt
   └── data/
       ├── train.parquet
       ├── benchmark_queries.parquet
       └── benchmark_items.parquet
   ```

   ```bash
   python -m jupyter lab solution.ipynb
   ```

6. Выберите ядро **Python (avito-services)**. В ячейке **«Настройки запуска»**
   выберите `DATA_SOURCE = "local"`.
   Оставьте `DATA_DIR = None` для папки `data/` или укажите путь к своей папке.
   Для первого запуска оставьте `ALLOW_MODEL_DOWNLOAD = True`,
   `REQUIRE_FINETUNE_CACHE = False`, `RUN_FINAL = True`.
   Зависимости уже установлены, поэтому `INSTALL_PACKAGES = False`.
   Выполните **Run All**. При стандартных путях `answer.csv` появится в корне проекта.

## Запуск в Kaggle

1. Импортируйте `solution.ipynb`. Подключите три Parquet-файла через **Add Input**,
   включите GPU и Internet для подготовки зависимостей и весов.
2. Примите условия Gemma на Hugging Face. В **Add-ons → Secrets** добавьте
   `HF_TOKEN` с правом чтения и разрешите доступ текущему ноутбуку.
3. При первой настройке поставьте `INSTALL_PACKAGES = True` и выполните только
   установочную ячейку. Перезапустите ядро, затем верните флаг в `False`.
4. В ячейке **«Настройки запуска»** выберите `DATA_SOURCE = "kaggle"`.
   `DATA_DIR = None` найдёт единственную папку с тремя файлами в `/kaggle/input`.
   Если наборов несколько, укажите точный путь к нужной папке из панели Input.
5. Для первого запуска используйте те же флаги, что локально, и выполните **Run All**.
   Скачайте `answer.csv` из `/kaggle/working/avito_candidate_generation/`.

`DATA_DIR` всегда указывает на файлы в среде, где работает ядро.
Локальная папка компьютера автоматически не переносится в Kaggle.

## Повторный запуск и результат

Полный запуск сравнивает девять вариантов, выбирает лучший по dev, оценивает test
и создаёт ответ. Для экспериментов без финальной сборки установите `RUN_FINAL = False`.

**Для первого запуска архив моделей и кэша не нужен.** После установки зависимостей
и настройки доступа к Gemma достаточно трёх Parquet-файлов. Ноутбук скачает исходные
веса энкодеров и выполнит обучение. Каталоги `models/` и `cache/` создаются автоматически.

Если продолжаете свой предыдущий запуск, оставьте прежний `OUTPUT_DIR`,
поставьте `ALLOW_MODEL_DOWNLOAD = False`, `REQUIRE_FINETUNE_CACHE = True`
и выполните ноутбук сверху вниз. Готовые веса и эмбеддинги используются повторно,
законченные эксперименты восстанавливаются из снимка.
Таблицы fit обрабатываются по 128 запросов, кэш кандидатов
ограничен 4 GiB. Отсутствующие временные таблицы восстанавливаются автоматически.

| В `OUTPUT_DIR` | Содержимое |
|---|---|
| `answer.csv` | Файл для платформы, ровно `query_id,answer` |
| `iteration_report.zip` | Таблицы метрик, диагностика, окружение и финальная проверка |
| `reports/notebook-v4/` | Отдельные CSV и JSON отчёта |
| `models/` | Веса энкодеров, CatBoost и финальный индекс |
| `cache/` | Эмбеддинги, промежуточные таблицы и снимки экспериментов |

CSV проверяется на полноту запросов, формат идентификаторов, отсутствие повторов
и лимит 50. В конце запуска ответ дважды формируется на CPU из созданных финальных
артефактов. Совпадение CSV проверяется по SHA-256. Эта проверка относится к повтору
из одних и тех же артефактов. Новое обучение на другом оборудовании может дать
численные отличия. Отправка на платформу выполняется вручную.
Исходные данные и создаваемые папки `models/`, `cache/` не входят в Git.

## Использованные инструменты

[BM25](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html),
[scikit-learn](https://scikit-learn.org/stable/modules/feature_extraction.html#text-feature-extraction),
[Multilingual E5](https://huggingface.co/intfloat/multilingual-e5-base) (MIT),
[EmbeddingGemma](https://huggingface.co/google/embeddinggemma-300m) (условия Gemma),
[Sentence Transformers](https://sbert.net/docs/package_reference/sentence_transformer/losses.html#cachedmultiplenegativesrankingloss),
[CatBoost PairLogit](https://catboost.ai/docs/en/concepts/loss-functions-ranking#pairlogit),
PyTorch, Transformers, NumPy, pandas, SciPy, PyArrow, Snowball, joblib и Matplotlib.
Ревизии моделей закреплены в ноутбуке. Обучение и поиск выполняются в своей среде
без внешних API.
